# Центральный Ярнам — Bloodborne: Hunter's Nightmare

Мобильная 3D-игра на Three.js r128. Публикуется как статический сайт GitHub Pages; сборщик и package manager не требуются.

## Структура

- `index.html` — разметка экранов, HUD, управления и подключения ресурсов.
- `style.css` — все стили игры и мобильного интерфейса.
- `js/00-state.js` — состояния игры, настройки и сохранения.
- `js/01-feedback.js` — HUD, уведомления и визуальная/звуковая обратная связь.
- `js/02-rendering.js` — Three.js-сцена, профили качества, освещение, карты теней и postprocessing pipeline.
- `js/03-models.js` — подготовка, анимация и загрузка моделей.
- `js/04-world.js` — геометрия локаций, поверхности и коллайдеры.
- `js/05-entities.js` — противники, объекты мира и загрузка локаций.
- `js/06-ui.js` — меню, прогресс, инвентарь и игровые действия.
- `js/07-gameplay.js` — игровой цикл, управление, старт игры и ориентация экрана.
- `MOB/` — модели персонажей и существ.

JavaScript подключён обычными отложенными скриптами в порядке `00`–`07`: это сохраняет существующие глобальные функции и inline-обработчики без перехода на ES-модули. Three.js r128, GLTFLoader и meshopt decoder загружаются с CDN.

## Маршруты и перемещение

Комнаты каждого этажа соединены детерминированной сетью с развилками и петлями; после первого босса игрок выбирает одну из двух открывшихся локаций, а следующий этап открывается после победы в любой ветке. В коридорах есть короткие пути с рычагами по обе стороны ворот. Между этажами доступны существующие лестницы и новый лифт с панелями вызова на обоих этажах; лифт перевозит игрока, если тот стоит на платформе.

## Производительность на телефонах

В «Настройки → Экран» доступны профили «Ультра» и «Средние». На «Ультра» включаются SSAO, Bloom, кинематографическая цветокоррекция и тени от луны; на мобильном устройстве ограничиваются pixel ratio и детализация эффектов. «Средние» отключают SSAO/Bloom, сохраняя облегчённую цветокоррекцию и сглаживание. Одна ближайшая точка (фонарь) получает динамические мягкие тени, чтобы не запускать карты теней для всех огней сразу. Стены и пол используют процедурные карты цвета, нормалей и шероховатости.

Для сенсорных устройств WebGL antialiasing отключён, а pixel ratio и разрешение теней ограничены профилем. Также сокращается число дождевых линий и пылинок. Загрузка GLB-моделей запускается после появления стартового экрана (или при нажатии «Начать охоту»), чтобы не совмещать её с первоначальной сборкой интерфейса.

## Запуск

Откройте `index.html` через статический HTTP-сервер или GitHub Pages. Для локального запуска, например, выполните `python3 -m http.server 8000` в корне репозитория.

## Работа над вертикальным срезом кафедрального квартала
- Текущий визуальный эксперимент ограничен стартовым залом нижнего этажа (`locationIndex === 1`, `floorIndex === 0`, `roomIndex === 0`). Арт загружается из `assets/levelgen/cathedral_ground_slice.glb`; источник сцены — `tools/levelgen/build_cathedral_slice.py` (Blender 4.x).
- Этот GLB — только визуальная геометрия. Не изменять сетки комнат, стены/полы-коллайдеры, лестницы, двери, спавны, прогресс, сохранения, HUD, управление и игровые состояния в рамках художественного прохода.
- Не использовать `tools/levelgen/build.sh` для локального среза кафедрального зала: он пересобирает двухэтажные данные и активный набор Spider Castle. Перегенерировать GLB среза отдельным скриптом.
- После пользовательской проверки не переходить к другим комнатам/этажам без отдельного явного «ок». На другом устройстве синхронизировать только закоммиченные и отправленные в GitHub изменения; браузерные игровые сохранения этим не переносятся.
- При продолжении сначала проверить `SESSION_HANDOFF_RU.md`, `TODO.md`, `git status` и актуальный `origin/main`; сохранять пользовательские изменения и не переписывать историю.
